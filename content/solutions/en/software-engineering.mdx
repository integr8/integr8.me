### Modern Architectures

| Pattern              | When to Use        | Benefit                       |
| -------------------- | ------------------ | ----------------------------- |
| **Microservices**    | Scale and autonomy | Independent deploy by domain  |
| **Modular Monolith** | Simplicity first   | Gradual evolution, simple ops |
| **Event-Driven**     | Decoupling         | Audit trail, scalability      |
| **CQRS/ES**          | Reads ≠ Writes     | Optimized performance         |
