## The Evolution of Data Architectures

For decades, organizations faced a dilemma: choose between the flexibility of **Data Lakes** or the performance of **Data Warehouses**. The **Lakehouse** architecture emerges as the definitive answer to this trade-off.

## What is Lakehouse?

Lakehouse is a data architecture that combines:

- **Cheap storage** from Data Lakes (object storage)
- **ACID transactions** from Data Warehouses
- **Schema enforcement** and evolution
- **Integrated governance and lineage**
- **Optimized performance** for BI and ML

## Table Formats: The Heart of Lakehouse

Open table formats are the key innovation enabling Lakehouse:

| Feature | Delta Lake | Apache Iceberg | Apache Hudi |
|---------|------------|----------------|-------------|
| **Creator** | Databricks | Netflix | Uber |
| **ACID** | ✅ | ✅ | ✅ |
| **Time Travel** | ✅ | ✅ | ✅ |
| **Schema Evolution** | ✅ | ✅ | ✅ |
| **Partition Evolution** | Limited | ✅ Native | Limited |
| **Hidden Partitioning** | ❌ | ✅ | ❌ |
| **Merge on Read** | ✅ | ✅ | ✅ |
| **Ecosystem** | Spark-centric | Multi-engine | Spark/Flink |

<Callout type="info" title="Our Recommendation">
  **Apache Iceberg** is consolidating as the market standard due to its open architecture and multi-engine support. Delta Lake is ideal if you're already in the Databricks ecosystem.
</Callout>

## Implementing a Lakehouse

### Reference Architecture with Iceberg

```python
# Creating an Iceberg table with PySpark
from pyspark.sql import SparkSession

spark = SparkSession.builder \
    .appName("LakehouseExample") \
    .config("spark.sql.catalog.lakehouse", "org.apache.iceberg.spark.SparkCatalog") \
    .config("spark.sql.catalog.lakehouse.type", "hadoop") \
    .config("spark.sql.catalog.lakehouse.warehouse", "s3://my-lakehouse/") \
    .getOrCreate()

# Create table with hidden partitioning
spark.sql("""
    CREATE TABLE lakehouse.events (
        event_id STRING,
        user_id STRING,
        event_type STRING,
        event_timestamp TIMESTAMP,
        properties MAP<STRING, STRING>
    )
    USING iceberg
    PARTITIONED BY (days(event_timestamp), event_type)
""")

# Time Travel - query historical data
spark.sql("""
    SELECT * FROM lakehouse.events
    FOR TIMESTAMP AS OF '2025-01-01 00:00:00'
""")
```

## Modern Lakehouse Stack

### For AWS

```yaml
stack:
  storage: S3
  table_format: Iceberg
  catalog: AWS Glue Data Catalog
  query_engines:
    - Amazon Athena (serverless SQL)
    - Amazon EMR (Spark)
    - Trino (federation)
  orchestration: Apache Airflow / Step Functions
  governance: AWS Lake Formation
```

### For Azure

```yaml
stack:
  storage: ADLS Gen2
  table_format: Delta Lake
  catalog: Unity Catalog (Databricks) or Hive Metastore
  query_engines:
    - Azure Synapse Serverless
    - Databricks SQL
    - Spark
  orchestration: Azure Data Factory
  governance: Microsoft Purview
```

### For GCP

```yaml
stack:
  storage: GCS
  table_format: BigLake (Iceberg)
  catalog: BigQuery Metastore
  query_engines:
    - BigQuery
    - Dataproc (Spark)
  orchestration: Cloud Composer
  governance: Dataplex
```
