## The Cloud Cost Challenge

With massive cloud computing adoption, many organizations face a common problem: **cloud bills that grow exponentially** without control or predictability. According to Flexera, companies waste an average of **32% of cloud spending**.

<Callout type="warning" title="Cost Alert">
  Without FinOps practices, it's common to see cloud bills doubling every 6-12 months while actual resource utilization remains below 40%.
</Callout>

## What is FinOps?

FinOps (Financial Operations) is a cultural practice that brings together technology, finance, and business teams to collaboratively manage cloud costs while maintaining speed and quality.

## Optimization Strategies by Cloud Provider

### AWS

```bash
# Identify underutilized EC2 instances
aws ce get-cost-and-usage \
  --time-period Start=2025-01-01,End=2025-01-31 \
  --granularity MONTHLY \
  --metrics "BlendedCost" "UnblendedCost" \
  --group-by Type=DIMENSION,Key=SERVICE
```

**Main cost levers:**
- **Savings Plans**: Up to 72% discount with commitment
- **Spot Instances**: Up to 90% discount for interruption-tolerant workloads
- **Graviton**: 20-40% more cost-effective than x86
- **S3 Intelligent-Tiering**: Automatic storage optimization

### Azure

```bash
# Optimization recommendations via Azure CLI
az advisor recommendation list \
  --category cost \
  --output table
```

**Main levers:**
- **Reserved Instances**: Up to 72% savings
- **Azure Hybrid Benefit**: Reuse Windows/SQL licenses
- **Spot VMs**: For batch and fault-tolerant workloads

### GCP

```bash
# Committed Use Discounts
gcloud compute commitments list --project=my-project
```

**Main levers:**
- **Committed Use Discounts**: Up to 57% discount
- **Preemptible VMs**: Up to 80% cheaper
- **Sustained Use Discounts**: Automatic for continuous usage

## Implementing a Tagging Strategy

A consistent tagging strategy is fundamental for cost allocation:

```yaml
# Example of mandatory tags policy
required_tags:
  - key: Environment
    values: [production, staging, development]
  - key: Team
    values: [platform, data, backend, frontend]
  - key: CostCenter
    values: [engineering, marketing, sales]
  - key: Project
    description: "Project or product name"
```

<Callout type="info" title="Tip">
  Use tools like AWS Tag Editor, Azure Policy, or GCP Organization Policy to enforce mandatory tags before resource provisioning.
</Callout>
