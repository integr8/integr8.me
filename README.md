# integr8.me

Site institucional da Integr8 - Consultoria DevOps, Cloud e Platform Engineering.

## Stack

- **Astro** - Static site generator
- **React** - Componentes interativos
- **Tailwind CSS + DaisyUI** - Styling
- **TypeScript** - Type safety

## Desenvolvimento

```bash
# Setup inicial (mise + deps + pre-commit)
make setup

# Servidor de desenvolvimento
make dev

# Build de produção
make build

# Preview do build
make preview

# Ver todos os comandos disponíveis
make help
```

## Estrutura

```
src/
├── components/     # Componentes React/Astro
├── content/        # Conteúdo MDX (solutions, blog, cases)
├── i18n/           # Internacionalização (ptbr, en)
├── layouts/        # Layouts Astro
├── pages/          # Rotas
└── styles/         # CSS global
```
